SWAPPING SOUNDS
===============

Easiest way: in the operator console, open the "Look & Sound" tab and click
"Replace..." next to any sound. Pick an mp3 / m4a / wav file and you're done.
It's remembered in this browser. "Reset" goes back to the built-in sound.

Folder way (handy if you move the game to another computer):
drop audio files into THIS folder using these exact names, then click
"Rescan sounds folder" in the Look & Sound tab (or just reload the page).
Any of .mp3, .m4a, .wav or .ogg works.

  theme.mp3          Theme music (title & winner screens, the Theme button)
  round-start.mp3    When a round starts
  reveal.mp3         Correct answer / an answer flips over
  wrong.mp3          Wrong answer / the big X
  buzz-in.mp3        Face-off buzzer (Q / P keys)
  points.mp3         The bank goes to a team
  applause.mp3       After a team wins a round
  winner.mp3         Winner screen & bonus goal reached
  bonus-answer.mp3   A bonus-round answer appears
  duplicate.mp3      Bonus round "try again" (D key)
  tick.mp3           Bonus timer, every second
  tick-final.mp3     Bonus timer, last 5 seconds
  time-up.mp3        Bonus timer hits zero

Any sound without a file keeps its built-in version.
A file picked with "Replace..." wins over a file in this folder.
Each sound also has its own volume slider in the Look & Sound tab.
